# Compare terminal features

Choose terminals and search by feature name, stable ID, sequence, or policy
label. Open a feature to inspect its specification, version, notes, and evidence.

**Unknown means unassessed, not unsupported.** Imported claims preserve the old
TDN tables and have not been reverified. Conflicting claims remain unknown.
A permission that denies an operation by default does not mean the terminal
cannot implement it. Aggregate records do not establish support for every
operation in the group.

The tables and [downloadable JSON database](assets/compatibility.json) are
built from [independent terminal files](registry.md). With JavaScript disabled,
all columns and rows remain available.
