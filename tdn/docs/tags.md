# Feature labels

Labels connect features across sequence families. They describe a shared
property, independently of a feature's standards status or emulator support.

The **Window Ops** label means the page documents controls governed by
[xterm's Window Ops policy](policies/window-ops.md). On pages covering several
features, the text identifies the controls to which the label applies.

The **Title Ops** label identifies controls that change the displayed title
or icon label under [xterm's Title Ops policy](policies/title-ops.md).
A page can carry both labels: restoring a saved title involves both policies,
while reporting a title uses Window Ops alone.
