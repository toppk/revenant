# Feature registry

Each ID names a protocol operation or a separately assessable behavior.
IDs are permanent and independent of documentation paths. For example,
`osc-8-hyperlinks` describes the hyperlink protocol, while `osc-8-link-id`
describes grouping links by their identifier.

Numbers need their namespace: `dec-mode-2027-grapheme-clusters` is a mode;
`text-color-emoji` is a rendering behavior without a control-sequence number.

[Compare terminals](../comparison.md) or read the [data contribution guide](../registry.md).
