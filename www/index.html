Revenant a modern X11 terminal that feels like xterm

Revenant was created to bring more terminal features to a familiar xterm experience. If you like xterm but don't want to give up modern features, give Revenant a try. It is not 100% identical, because it thoughtfully adds new features you may not have used yet — but you will see mostly the same menus, the same translations, and the ~/.Xresources lines you wrote twenty years ago, with the terminal engine underneath replaced by libghostty-vt. This is still an ongoing effort.
